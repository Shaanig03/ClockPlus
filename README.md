⏰ Clock Plus (1.2)
--------------------------------

- ⏰ Clock Plus is an alarm software made for Windows, it has some more features than the default windows Clock alarm application

Features:

   - it includes alarms(ofc), timers and a stopwatch
   
   - alarm:

		- set an alarm by time AM/PM
		
		- set alarm repeating days
		
		- set alarm for a specific date/s, every month or every year
		
		- set an alarm sound 
		
		- can add commands to alarms that is executed on alarm
		
		- can snooze an alarm (similar to windows default one)
		
		- (User Interface) you should see the exact remaining time for the alarm time

 - timer:

	- set a time
		
	- set an alarm sound 
		
	- can add commands to timers that is executed when the timer finishes
		
  - alarm/timer commands:
	
	- open application / folder
		
	- close application 
		
	- open URL
		
	- turn on/off computer sleep mode 
		
	- shutdown computer 
		
	- restart computer 
		
  - stopwatch:
	
	- note: you probably won't be using this >_<
	
  - notification system
		
	- for alarms you can snooze 
		
  - settings:
	
	- you can auto-run the application on windows start
		
	- (deprecated)(option) alarm notification expire time
		
	- alarm/timer sound volume
		
	- a cat for some ambient warmthness ^_^
		
	- includes some notes
	
 - Note: when you press the close button in the application it minimizes the app to the system tray(similar to Steam), to completely terminate the application you right click the application from the system tray and hit 'Close Application'
